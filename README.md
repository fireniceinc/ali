# ALI Android Bootstrap

Minimal Android bootstrap for Fire & Ice / Architecture B. This is packaging/bootstrap infrastructure, not a claim to contain the canonical ALI continuity/cognition substrate.

## Build with GitHub Actions
Upload the contents of this folder to the repository root (or make this directory its own repository root). The workflow triggers on pushes to `main` and can also be run manually. Download `ALI-debug-apk` from the completed Actions run.

## Local build
With a compatible JDK, Android SDK, and Gradle available: `gradle assembleDebug`.
